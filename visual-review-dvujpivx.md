# Visual Review Notes

The refreshed desktop views use a cohesive Light Labs support-operations language: a deep forest navigation shell, off-white work area, mint verification cues, serif operational headlines, and compact technical labels. The Slack Support route was tightened to present the newest verified messages rather than an unbounded historical list. The account-mapping table retains a horizontal-scroll fallback for narrower screens, and its connection-logic cell is explicitly left aligned for readability.

The revised information architecture was confirmed across the Slack Support, Account Mapping, Support Performance, and Integrations routes. Pylon and LIMS-facing UI are absent from these active views; email appears only as contextual support information rather than an automated input queue.

The final mobile viewport check confirms that Slack Support, Account Mapping, Support Performance, and Integrations are all visible as a two-column navigation grid without horizontal scrolling.

The updated desktop Account Mapping view loads both AM/AE portfolios successfully. The selected owner shows 120 direct brands, 40 Co-Man accounts, 386 brands contained in Co-Man portfolios, and 546 total managed accounts. The table visibly distinguishes direct and nested brands while summarizing contact-level permission counts. The Integrations view successfully loads source-tagged HubSpot field definitions with long-form descriptions and searchable/writable state indicators; the Testing Platform and support source tabs are available for the equivalent catalogs.

The mobile views retain the owner selector, all four portfolio summary cards, account-type badges, and the field-catalog source selector. Wide portfolio and catalog tables remain horizontally scrollable while the page hierarchy and key account totals stay readable at the compact breakpoint.
